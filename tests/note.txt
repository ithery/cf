literally comprehensive coverage of all of it is not realistically achievable.

[Wave 0 - pre-flight bug fixes found while investigating baseline failures]
Fixed 3 of the 20 baseline failures (all real bugs, not test/env issues):
1. cstr::replaceLast() was missing the `if ($search === '') return $subject;`
   guard that Laravel's Str::replaceLast has - empty search inserted
   $replace at the end of the string instead of being a no-op.
   -> system/helpers/cstr.php
2. tests/Base/ReflectorTest.php::testUnionTypeName() eval()'d a helper class
   F inside `namespace Illuminate\Tests\Support` (leftover from a direct
   Laravel test port, never adapted) then referenced unqualified `F::class`
   from the global namespace - class never found. Also referenced Laravel's
   `Model` instead of this framework's `CModel`. Fixed both.
3. c::get() (the data_get()-equivalent dot-notation getter) built a
   `$segmentMap` array EVERY loop iteration that eagerly computed
   `array_key_first()`/`array_key_last()` over the *entire* target
   (via c::collect($target)->all(), which calls ->toArray() on
   Arrayable objects) regardless of whether the current segment was
   actually '{first}'/'{last}' or just a plain key. This meant every
   single c::get($obj, 'somePlainKey') call on a non-array object forced
   a full toArray() conversion first - wasteful, and broke strict Mockery
   expectations that didn't mock toArray() (ModelCollectionTest > contains
   key and value). Rewrote to only compute array_key_first/last lazily
   when the segment actually is '{first}'/'{last}'. This is a hot-path
   framework function (data_get() equivalent, used everywhere) so I ran
   the FULL test suite before/after: 497->500 passed, 20->17 failed
   (only the pre-existing sqlite-driver-missing ones remain), no new
   failures introduced.

Remaining 17 baseline failures are ALL because pdo_sqlite is not installed
for the active PHP 8.2 CLI in this sandbox (php7.4-sqlite3 is installed but
not php8.2-sqlite3; confirmed via `PDO::getAvailableDrivers()` - sqlite not
listed). No passwordless sudo available (`sudo -n true` fails), so I cannot
install system/vendor/PHPUnit-> the missing apt package myself. These are
