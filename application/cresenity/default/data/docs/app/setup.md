# Application - Setup

### Default View

By default, CApp loads the `page.blade.php` view as the page layout. You can override this view by creating your own `page.blade.php` in your application's `views/` directory.

You can also change which view is loaded:

```php
<?php
// Use a different view name
c::app()->setViewName('dashboard');  // loads views/dashboard.blade.php

// Use a specific view for the login page
c::app()->setViewLoginName('auth.login');
```

### Page Layout Template

A typical CApp page layout view:

```html
<!DOCTYPE html>
<html lang="{{ c::locale() }}">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{{ $title }}</title>
    @CAppSeo
    <link rel="icon" href="{{ c::media('img/favico.png') }}">
    @CAppStyles
</head>
<body>
    @CAppContent

    @CAppScripts

    <script>
        window.addEventListener('cresenity:loaded', () => {
            // runs after the Cresenity JS object is fully loaded
        });
    </script>
</body>
</html>
```

### Blade Directives

CApp provides special Blade directives for use in page layout views:

| Directive | Description |
|-----------|------------|
| `@CAppSeo` | Outputs SEO meta tags configured via `c::app()->seo()` |
| `@CAppStyles` | Outputs all CSS assets registered by the theme and `c::manager()->registerCss()` |
| `@CAppContent` | Outputs the page content generated by CApp (elements, views, components) |
| `@CAppScripts` | Outputs all JavaScript assets registered by the theme and `c::manager()->registerJs()` |

### Setting the View from Controller

Override the view on a per-request basis from your controller:

```php
<?php
class Controller_Home extends CController {
    public function index() {
        $app = c::app();
        $app->title('Home');
        $app->setView('welcome');

        return $app;
    }

    public function dashboard() {
        $app = c::app();
        $app->title('Dashboard');
        $app->setViewName('admin');

        return $app;
    }
}
```

### Page Title

Set the page title that appears in the browser tab and in the `{{ $title }}` variable:

```php
$app->title('Dashboard');
// or
$app->setTitle('Dashboard');
```

### SEO Configuration

Configure meta tags for search engines and social sharing:

```php
$app->seo()->setTitle('My Page');
$app->seo()->setDescription('Page description');
$app->seo()->setKeywords('keyword1, keyword2');
```

### Registering Assets

Register additional CSS and JavaScript files for the current page:

```php
// Register CSS
c::manager()->registerCss('my-app/custom.css');

// Register JavaScript
c::manager()->registerJs('my-app/custom.js');

// Register a pre-built module (bundles of CSS/JS)
CManager::registerModule('bootstrap-4');
```
