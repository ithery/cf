# Change Log 1.8


- CF
  - Adding support for PHP 8.4
  - Fix missing `cf` marker file required by `phpcf` CLI to locate the framework root — without it, `phpcf`'s upward directory search failed silently and it required() an absolute path from filesystem root instead of `system/core/Bootstrap.php`
  - Fix a shadowed loop variable in `cstr::is()` and `cstr::isMatch()` (the `foreach` reused the `$pattern` parameter name)
- CRouting
  - **Security:** `CController::callAction` now validates method visibility — only `public` methods can be called via URL. Protected and private methods return 404
  - **Security:** Magic methods (`__construct`, `__destruct`, `__call`, etc.) are blocked from being routed directly
  - **Security:** Internal controller methods (`callAction`, `middleware`, `getMiddleware`) are blocked from URL access via a configurable blacklist (`CController::getBlockedMethods`)
  - **Security:** `CRouting_RouteFinder` now rejects methods inherited from `CController` base class from being auto-discovered as routes
  - **Feature:** Auto-discovered routes now support HTTP verb prefixes on controller methods. Prefix a method name with the HTTP verb to restrict which methods it accepts:
    - `getDetail($id)` — responds to GET and HEAD only
    - `postStore()` — responds to POST only
    - `putUpdate($id)` — responds to PUT only
    - `deleteRemove($id)` — responds to DELETE only
    - `anyProcess()` — responds to all HTTP verbs (explicit)
    - `index()` — no prefix, responds to all HTTP verbs (backward compatible)
  - Requesting a URL with the wrong HTTP verb now returns `405 Method Not Allowed` with a proper `Allow` header, instead of 404
  - Controllers using `__call` magic method as a catch-all continue to work correctly
- CDatabase
  - Fix `compileTableExists` method signature in SqliteGrammar, SqlServerGrammar, and OdbcGrammar to match parent class
  - Fix PostgresBuilder caller to pass `$schema` and `$table` arguments
  - Fix PHP 7.4 compatibility in `CDatabase_Grammar` — replace `str_contains()`, `??=`, first-class callables, and deprecated string interpolation
  - Fix `ModelDataProvider` correlating BelongsToMany sort subqueries — sorting a data provider grid by a column through a plain `belongsToMany` relation (not just `belongsTo`) previously caused "Cardinality violation: Subquery returns more than 1 row"
  - Replace `match()` with if/elseif in Schema Builder for PHP 7.4 compatibility
  - Add missing PHPDoc across `CDatabase_Connection` compat methods
  - Fix `transactionsManager` property typo in `handleRollBackException` that silently skipped calling the transaction manager's rollback on lost-connection errors
  - Treat MySQL error 1020 ("Record has changed since last read") as a retryable concurrency error alongside deadlocks and lock wait timeouts
- CElement
  - **Feature:** Generic theme-driven CSS classes — any `CElement` subclass can now declare `protected $themeType = '<key>';` (eg. `'select'`, `'button'`, `'widget'`) to automatically pick up extra classes from the active theme's `data.<key>.classes` config (`c::theme('<key>.classes')`), letting a theme add classes like `ki-select`/`ki-button`/`ki-card` per element type without touching the component's own code. Purely additive — an element with no `$themeType` set, or a theme with no matching key, renders exactly as before. `CElement_FormInput_Select` (which already had this ad-hoc for `select.classes`) now uses the generic hook instead; also wired up for `CElement_FormInput_Text`/`Textarea`/`Checkbox`/`Radio`/`SelectSearch`, `CElement_Element_Button`, `CElement_Component_Widget`, and `CElement_Component_DataTable`
  - **Feature:** `CElement_FormInput_Text::setIcon($icon)` — renders an icon (eg. a Tabler `ti ti-mail` class) in a Bootstrap input-group prepended to the field. Not calling it renders the bare `<input>` exactly as before (zero breaking change)
  - Chart component now support dataOptions
  - Give support to bootstrap-5
  - Add setDataFromCollection for SelectSearch component
  - **Repeater:** Add `setCanAdd`, `setCanDelete`, `setAddLabel`, `setDeleteLabel`, `setAddButtonClass`, `setDeleteButtonClass`, `setMaxItem` methods. JS now supports `maxItem` (hides add button at limit) and properly re-initializes controls in cloned rows
  - **SelectTwo:** New `CElement_FormInput_SelectTwo` — Select2 input with cres.js auto-initialization via `cres-config` attribute. Works correctly inside Repeater (auto-init on clone via MutationObserver). Supports AJAX search, format templates, multiple, allowClear, prependData, dependsOn, setValue with selectedData, and automatic modal detection
  - **TreeView:** Consolidated the legacy `CElement_Tree` (ajax file/folder browser) into `CElement_Component_TreeView`. All "Tree" terminology renamed to "TreeView" (`addTree()` → `addTreeView()`, `CAjax::TYPE_TREE_VIEW`, cres.js `component:TreeView`). `setNodes()` accepts either a fixed array or a callable for true per-node ajax lazy-loading (each expand click fetches just that node's children), using `CElement_Component_TreeView_Node`'s `id`/`hasChildren` properties
  - **Calendar:** Reworked `CElement_Component_Calendar` around a `CalendarEvents`/`CalendarEvent` value-object pair (both implement `Arrayable`). `setEvents()` accepts a fixed array or a callable for ajax-loaded events per visible date range. Added fullCalendar locale/button-text i18n (`element/calendar` language files)
  - **File Manager:** Migrated `CElement_Component_FileManager`'s client-side behavior from the vendored jQuery `fm.js`/`fm.css` into cres.js (`component:FileManager`). Fixed several pre-existing bugs found along the way: the move-to-folder picker response was fetched but never displayed, the download endpoint called renamed/removed Flysystem methods (`getMimetype`/`getSize` → `mimeType`/`size`), grid/preview mime icons were missing a required nested markup element, and the mobile tree-toggle button targeted a class that didn't exist in the markup. All DOM lookups are now scoped to each instance's own root element, so multiple File Manager widgets can coexist on one page
  - **Nestable:** Add missing PHPDoc
  - **ActionList:** Add missing PHPDoc; fix missing semicolon in the currency formatter
  - Align `CElement_FormInput::addValidation()` with `CElement_Component_Form`'s Laravel-style validation — it previously fed a dead validationEngine CSS-class renderer that no client-side plugin consumed
  - **DataTable:** non-ajax mode (`setApplyDataTable(false)`) now shows the configured empty-state label instead of rendering a blank `<tbody>` when there's no data
  - **Deprecated:** `addTemplate()`/`CElement_Template` in favor of `addView()`
  - **Widget/TabList:** Reworked into cres.js-driven `cres:element`s. `Widget::setCollapse()` now adds a working optional header-chevron collapse toggle (the old compat shim wrote to a nonexistent property, so it never actually collapsed). `TabList`/`Tab` drop their inline jQuery-built `html()`/`js()` for a proper view + cres.js module, fixing nested ajax-loaded tab lists
  - **File Manager:** Reject path traversal (`..`/`/` segments) in item name and working-dir input; catch the correct Flysystem v3 delete exceptions (`UnableToDeleteFile`/`UnableToDeleteDirectory` — the v1-only `FileNotFoundException` it caught before could never match); fix the sort dropdown rendering inline instead of as an overlay below the navbar's collapse breakpoint, and a z-index conflict that let grid item badges/icons bleed through it
