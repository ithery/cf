# Change Log 1.8

## CF

- Add support for PHP 8.4
- Fix the missing `cf` marker file that `phpcf` needs to locate the framework root
- Fix a shadowed loop variable in `cstr::is()` and `cstr::isMatch()`
- Fix `cstr::replaceLast()` missing an empty-search guard
- Fix `c::get()` eagerly computing `array_key_first()`/`array_key_last()` on every path segment

## CRouting

- **Security:** `CController::callAction()` only calls `public` methods; protected and private return 404
- **Security:** block magic methods (`__construct`, `__call`, …) from being routed
- **Security:** block internal controller methods via `CController::getBlockedMethods()`
- **Security:** `CRouting_RouteFinder` rejects methods inherited from the `CController` base class
- Auto-discovered routes support HTTP verb prefixes on method names (`getDetail()`, `postStore()`, `putUpdate()`, `deleteRemove()`, `anyProcess()`); an unprefixed name still answers every verb
- The wrong HTTP verb returns `405 Method Not Allowed` with an `Allow` header instead of 404
- Controllers using `__call` as a catch-all keep working

## CDatabase

- Fix `compileTableExists()` signatures in the Sqlite, SqlServer, and Odbc grammars, and the `PostgresBuilder` caller
- Fix `CDatabase_Query_Grammar_SqlServerGrammar::wrapTable()` having a signature incompatible with its parent — a fatal the instant the dialect was instantiated
- Fix `CDatabase_Schema_Grammar_{Postgres,SqlServer}Grammar` being completely unloadable from LSP-violating signatures, and the same bug in `MariaDbGrammar::compileRenameColumn()`
- Fix `CDatabase_Schema_Grammar_SqlServerGrammar` never overriding `wrapValue()`, so it quoted identifiers with double quotes instead of square brackets
- Fix `CDatabase_Query_Grammar::compileBasicHaving()`/`compileHavingBetween()` duplicating the `boolean` prefix, producing `having and and …`
- Fix `CDatabase_Schema_Blueprint::removeColumn()` reading `$c['attributes']['name']` on a `CBase_Fluent` — every call threw
- Fix `CDatabase_Schema_Blueprint::dropTimestamps()`/`timestampsTz()` using the common `created_at`/`updated_at` naming while `timestamps()` creates `created`/`updated`
- Fix the `transactionsManager` property typo in `handleRollBackException()`, which skipped the rollback on lost-connection errors
- Fix `ModelDataProvider` correlating `belongsToMany` sort subqueries ("Subquery returns more than 1 row")
- Fix `CDatabase_Query_Builder::addSelect()` shadowing its own `$column` parameter, and a garbled `paginate()` docblock
- Treat MySQL error 1020 as a retryable concurrency error alongside deadlocks and lock wait timeouts
- PHP 7.4 compatibility in `CDatabase_Grammar` and the Schema Builder: replace `str_contains()`, `??=`, `match()`, first-class callables, and deprecated interpolation
- Add missing PHPDoc across the `CDatabase_Connection` compat methods and `CDatabase_Schema_MongoDB_Blueprint`

## CModel

- Fix `CModel_Nested_NestedSet::isNode()` checking `CModel_Nested_Trait`, an unused alias, so every nested-set relation threw `Model must be node`
- Fix `CModel_Trait_Attributes` using a bare `Attribute::class`, which resolved to PHP's built-in `\Attribute` and silently disabled the whole `CModel_Casts_Attribute` accessor/mutator feature
- Fix `CModel_Casts_Attribute` missing the `$withCaching` property that `Attributes.php` reads unconditionally
- **Security:** fix bearer-token lookup hashing the incoming token with `c::hash()` (salted per call) instead of a deterministic `hash('sha256', …)`, which broke bearer-token auth entirely
- Fix `CModel_Collection::contains()` always forwarding three arguments to its parent, breaking `operatorForWhere()`'s `func_num_args()` dispatch
- Fix `MetableTrait::setManyMeta()` calling a nonexistent `unsetRelation('meta')`, plus a deprecated `${var}` interpolation in `scopeOrderByMetaNumeric()`
- Scope `CacheableTrait`'s cache-key flush file per app instead of one shared path
- Add the `TranslationHasBeenSet` event and expand `HasTranslationTrait`
- Nested set: fix `bootNestedTrait()` never registering the `deleted`/`restored` events, so deleting a node orphaned every descendant and silently corrupted the tree
- Nested set: fix `setDepthWithSubtree()` never cascading a moved subtree's new depth, and `actionBeforeOrAfter()`/`actionRoot()` never calling it at all
- Nested set: fix `refreshNode()` only re-fetching `lft`/`rgt`, leaving depth stale
- Nested set: fix `fixTree()`/`rebuildTree()` deriving depth from an unsaved parent, compounding errors down the tree
- Nested set: fix `restoreDescendants()` calling `getDeletedAtColumn()`, which does not exist on this framework's primary soft-delete trait
- Nested set: fix `rawNode()`'s `$depth == null` check to `=== null`
- Nested set: add `tests/Model/NestedSetTest.php` (26 tests) against a real database; document `CModel_Nested_Move` and `CModel_Nested_Builder` as dead code
- Fix PHPDoc parse errors in `CModel`/`CModel_Query` and a wrong `@throws` in `CModel_Trait_Attributes`
