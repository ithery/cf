# Change Log 1.8


- CF
  - Adding support for PHP 8.4
- CRouting
  - **Security:** `CController::callAction` now validates method visibility — only `public` methods can be called via URL. Protected and private methods return 404
  - **Security:** Magic methods (`__construct`, `__destruct`, `__call`, etc.) are blocked from being routed directly
  - **Security:** Internal controller methods (`callAction`, `middleware`, `getMiddleware`) are blocked from URL access via a configurable blacklist (`CController::getBlockedMethods`)
  - **Security:** `CRouting_RouteFinder` now rejects methods inherited from `CController` base class from being auto-discovered as routes
  - **Feature:** Auto-discovered routes now support HTTP verb prefixes on controller methods. Prefix a method name with the HTTP verb to restrict which methods it accepts:
    - `getDetail($id)` — responds to GET and HEAD only
    - `postStore()` — responds to POST only
    - `putUpdate($id)` — responds to PUT only
    - `deleteRemove($id)` — responds to DELETE only
    - `anyProcess()` — responds to all HTTP verbs (explicit)
    - `index()` — no prefix, responds to all HTTP verbs (backward compatible)
  - Requesting a URL with the wrong HTTP verb now returns `405 Method Not Allowed` with a proper `Allow` header, instead of 404
  - Controllers using `__call` magic method as a catch-all continue to work correctly
- CDatabase
  - Fix `compileTableExists` method signature in SqliteGrammar, SqlServerGrammar, and OdbcGrammar to match parent class
  - Fix PostgresBuilder caller to pass `$schema` and `$table` arguments
  - Fix PHP 7.4 compatibility in `CDatabase_Grammar` — replace `str_contains()`, `??=`, first-class callables, and deprecated string interpolation
- CElement
  - Chart component now support dataOptions
  - Give support to bootstrap-5
  - Add setDataFromCollection for SelectSearch component
  - **Repeater:** Add `setCanAdd`, `setCanDelete`, `setAddLabel`, `setDeleteLabel`, `setAddButtonClass`, `setDeleteButtonClass`, `setMaxItem` methods. JS now supports `maxItem` (hides add button at limit) and properly re-initializes controls in cloned rows
  - **SelectTwo:** New `CElement_FormInput_SelectTwo` — Select2 input with cres.js auto-initialization via `cres-config` attribute. Works correctly inside Repeater (auto-init on clone via MutationObserver). Supports AJAX search, format templates, multiple, allowClear, prependData, dependsOn, setValue with selectedData, and automatic modal detection
- CNavigation
  - Fix icon prefix logic in SidenavRenderer, MenuRenderer, and Navigation Helper — now correctly handles Themify (`ti-`), Linearicons (`lnr`), and PE Icon 7 (`pe-`) icon classes without adding `icon-` prefix
- CTrait
  - Fix `DependsOn::getDependsOnValueJavascript` — add missing `getQuerySelector()` call on selector object
- Cres JS
  - Add `SelectTwo` control in `element/control/SelectTwo/` — reads config from `cres-config` attribute, initializes Select2, handles dependsOn (passes values as AJAX params, re-inits on change), and modal z-index auto-detect
  - Add `DependsOn` runner in `element/depends/` — generic JS library for dependsOn behavior
  - Repeater: add `resetClonedControls()` to clean up Select2/cres-element state on cloned rows
  - Refactor `DownloadProgress` from Cresenity.js into standalone module `module/DownloadProgress.js`
  - Fix `isUsingBootstrap()` missing return statement
  - Fix `handleJsonResponse` typo in error message
  - Fix `reload` complete callback checking wrong condition (`onBlock` instead of `onUnblock`)
- CAjax
  - Now ajax file upload gives return errCode and errMessage and previous format is wrapped in data key
- CApi
  - Minor bug fixes
  - Fix select search on modal
  - Support youtube shorts on editorjs component
- CApp
  - Adding default css for bootstrap-5
  - **Deprecated:** `capp.js` is deprecated and should be removed from theme JS config. `capp.js` contains a legacy `Cresenity` constructor that conflicts with the modern `cres.js` bundle — when both are loaded, `cres.js` skips initialization because `window.cresenity` is already set by `capp.js`, preventing `createWebSocket()`, `cresenity:loaded` event, and other modern features from working. The framework automatically loads `cres/dist/cres.js` via `@CAppScripts`, which replaces all functionality from `capp.js`, `cresenity.js`, and `cresenity/cresenity.bs4.js`. Remove these from your theme `js` array:
    ```php
    // Remove these from theme config:
    'capp.js',
    'cresenity.js',
    'cresenity/cresenity.bs4.js',
    ```
- CDaemon
  - Extract `CDaemon_RunnerAbstract` base class — eliminates code duplication across `CDaemon_Runner`, `CDaemon_Supervisor_Runner`, `CDaemon_Supervisor_WorkerRunner`
  - Move network server classes from `CDaemon/Worker/` to `CDaemon/Server/` — separates network server (TCP/WebSocket) from parallel task (fork/IPC) concerns. Old class names remain as backward-compatible wrappers
  - New `CDaemon_Server` facade, `CDaemon_Server_EventLoop`, `CDaemon_Server_Constant` — replaces all Workerman references with CF-native implementations
  - Move `CDaemon_WorkerProcess` to `CDaemon_Supervisor_WorkerProcess` (old name still works)
  - Add configurable `daemon.php_binary` config — allows overriding the PHP binary path used by daemon runners
  - Fix critical bug: `parentPid` assignment (`==` vs `=`) in `ServiceAbstract`
  - Fix PHP 8 compatibility: `is_resource()` checks for SysV handles, `shm_detach` null guard, `callCount` type error
  - Fix `Core_*` PHPDoc references — replaced with CF class names
  - Add `getCallCount()`/`setCallCount()` to `MediatorAbstract`, `checkEnvironment()` to `ViaInterface`
- CPagination
  - Add `#[\ReturnTypeWillChange]` attribute to `count()`, `getIterator()`, `offsetExists()`, `offsetGet()`, `offsetSet()`, `offsetUnset()`, `jsonSerialize()` for PHP 8.1+ compatibility
